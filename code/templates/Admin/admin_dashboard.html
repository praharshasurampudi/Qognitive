Admin Qognitive Dashboard




Qognitive is a Quiz Master Project that provides a platform for multiple students to effectively study for numerous courses. The platform supports two distinct user roles: Administrator and Students, ensuring an organized learning system.

The Administrator of Qognitive is responsible for managing the platform, ensuring a well-organized and efficient learning environment. They oversee the creation and organization of subjects, chapters, and quizzes, providing students with structured study materials.

Administrators have the ability to create and customize quizzes, set time limits, and monitor student progress. Additionally, they regulate user activity to maintain smooth interactions and uphold the integrity of the learning process. The platform is built using Flask for a lightweight yet powerful back-end, Jinja2 templating with HTML and CSS for a responsive front-end, and SQLite as the exclusive database for efficient data management. Through these tools, administrators help ensure that Qognitive remains an intuitive and interactive platform, making exam preparation structured, engaging, and accessible.
